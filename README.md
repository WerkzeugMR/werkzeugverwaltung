# Werkzeugverwaltung – Komplettpaket Schritte 1–4

Enthalten:

1. Mitarbeiterverwaltung
   - Host: bauerhin.b@gmail.com
   - Host-Kennnummer: 0606
   - Mitarbeiter melden sich mit mitarbeiter@marcoreiss.com an.
   - Jeder Mitarbeiter hat eine eigene 4-stellige Kennnummer.
   - Kennnummer wird bei Ausgabe und Rückgabe geprüft.

2. Reparatur
   - Host kann Werkzeuge als „In Reparatur“ markieren.
   - Werkzeuge in Reparatur können nicht ausgeliehen werden.
   - Host kann sie wieder freigeben.

3. 3-Monats-Verlauf
   - Host kann alle Ausgaben der letzten 3 Monate einsehen.
   - Offene und bereits zurückgegebene Vorgänge werden angezeigt.
   - Mitarbeiter, Kennnummer, Aus-/Rückgabe und Bemerkungen werden angezeigt.

4. PDF
   - Der Host kann den 3-Monats-Verlauf als PDF herunterladen.

WICHTIG:
Vor dem ersten Einsatz den kompletten Inhalt der schema.sql im Supabase SQL Editor ausführen.
Die index.html enthält die bereits konfigurierte Supabase-Verbindung.
