# Werkzeugverwaltung – Host: Mitarbeiter löschen

Neue Funktion:
- Host kann Mitarbeiter in der Mitarbeiterliste über „Löschen“ endgültig löschen.
- Die bisherigen Ausleihen bleiben im Verlauf erhalten.
- Der Mitarbeitername wird vor dem Löschen in den historischen Ausleihungen gespeichert.

WICHTIG:
1. Die komplette schema.sql im Supabase SQL Editor ausführen.
2. Die neue index.html auf GitHub Pages hochladen.
3. Strg+F5 zum Aktualisieren.
